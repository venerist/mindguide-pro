# 🧠 MindGuide Pro: Enterprise Mental Health Literacy Chatbot

**MindGuide Pro** adalah aplikasi chatbot berbasis Artificial Intelligence yang dirancang untuk memberikan edukasi mengenai dasar-dasar psikologi dan literasi kesehatan mental secara profesional. Aplikasi ini dibangun sebagai **Final Project** dalam program integrasi LLM & Gemini API untuk Data Scientist.

## 🚀 Fitur Utama
* **Akademis & Faktual**: Menggunakan **DSM-5 (Diagnostic and Statistical Manual of Mental Disorders, Fifth Edition)** sebagai referensi utama untuk kriteria, terminologi, dan klasifikasi psikologi.
* **Modern Enterprise UI**: Antarmuka pengguna yang bersih, minimalis, dan elegan dengan nuansa *soft purple* dan *lavender*.
* **Chatbot Berbasis AI**: Menggunakan model `gemini-2.0-flash` untuk pemrosesan bahasa alami yang responsif dan cerdas.
* **Formal & Empatik**: Dikonfigurasi dengan gaya bahasa Indonesia yang formal namun tetap menenangkan, sesuai untuk domain kesehatan mental.
* **Parameter Kreatif Teroptimasi**: Pengaturan *temperature* rendah (0.2) untuk memastikan jawaban yang konsisten dan meminimalkan halusinasi AI.

## 🛠️ Teknologi yang Digunakan
* **Bahasa Pemrograman**: Python 3.11+
* **Framework UI**: Streamlit
* **AI SDK**: Google Generative AI SDK
* **Version Control**: Git & GitHub
